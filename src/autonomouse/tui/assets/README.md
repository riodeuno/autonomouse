# The viewer's art

The board viewer's splash (`autonomouse.tui.logo`, `autonomouse.tui.splash`) plays these
files: 120-column dark-mode ANSI art in Unicode quadrant blocks, 24-bit colour, neutral
strokes pure white.

- `animation/frame_00.ans` to `animation/frame_07.ans`: the eight frames of the
  animation, one every 300 ms, in a loop. The mice stay still, the ground moves left one
  cell a frame and the flag flutters.

The viewer's header shows no logo: the art belongs to the splash alone.
