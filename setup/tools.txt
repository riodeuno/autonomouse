# Tools list for autonomouse's install.sh (sys-f2)
#
# Every tool the orchestrator and worker instructions need, pinned to one exact
# version and one cryptographic digest of the exact artifact that version resolves
# to, so install.sh downloads bytes and checks them before trusting them — never
# a moving "latest" pointer. The one exception is Claude Code: it is the latest
# release from Anthropic's own installer and updates itself, so a pin of ours would
# be out of date within days (see its block below).
#
# Target: bare Ubuntu 24.04 LTS (noble), on amd64/x86_64 and on arm64/aarch64. Every amd64
# pin below was resolved and independently verified (downloaded and hashed, or cross-checked
# against a second independent source) on 2026-09-22. Every arm64 pin ("source (arm64)",
# "sha256 (arm64)") is the same version, resolved on 2026-10-16 from the vendor's own
# checksums file (uv, gh, gum, node) or from the Ubuntu ports archive's Packages index of
# the same release and pocket (the apt packages), and each artifact was then downloaded and
# hashed to the same digest. An apt package's arm64 .deb comes from ports.ubuntu.com, which
# Ubuntu's arm64 images already use; "_amd64.deb" in an install line below reads
# "_arm64.deb" on arm64. Re-run the "source" lookup and re-hash to bump a pin; never
# hand-edit a digest.
#
# Format: one block per tool, blank-line separated.
#   tool     - name as install.sh and this file's readers refer to it
#   used for - which instruction (orchestrator.md / worker.md) or card names it,
#              or "bootstrap" for a tool the goal names that the docs do not
#   kind     - apt-deb | github-release | npm | official-installer
#   version  - the exact pinned version string
#   source   - the exact URL the artifact and its digest were fetched from
#   sha256 / sha1+sha512 - the verified digest of that exact artifact (none for
#              official-installer, the one kind that has no pin)
#   source (arm64), sha256 (arm64) - the same for the arm64 build of that version (an apt-deb's
#              source is the Ubuntu ports Packages index); an npm package that is pure
#              JavaScript has an "arm64" note instead of a second pin
#   install  - how install.sh turns this pin into an installed binary
#   verify   - the command install.sh's checklist runs to confirm success

tool: Claude Code
used for: bootstrap (this whole system's own control loop runs on it; super-orchestrator.md checks `gh auth status` alongside it; sys-f3 registers its MCP servers and checks `claude auth status`)
kind: official-installer
version: latest (the installer fetches the newest release, and Claude Code then updates itself)
source: https://claude.ai/install.sh (Anthropic's official installer, documented at https://code.claude.com/docs/en/setup; it downloads the release from https://downloads.claude.ai and checks its sha256 against Anthropic's manifest there)
install: no pin and no checksum of ours; this is the one tool the header's rule does not cover. install.sh first removes any npm copy of `@anthropic-ai/claude-code` (the one in ~/.local and the one in the node folder), then runs the official installer, which links ~/.local/bin/claude into ~/.local/share/claude/versions/. Logging in (`claude auth status` / the login flow) is a separate, un-pinnable step — sys-f3's job
verify: claude --version
